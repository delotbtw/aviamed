# 03. Роли и матрица прав

*Черновик v0.1, 26.10.2026.*

## 1. Роли

| Роль | Код | Примечание |
| --- | --- | --- |
| Администратор | `admin` | Управление системой, не работает с медданными по умолчанию |
| Регистратура | `registrar` | Организация приёма, видит статусы, но не результаты осмотров |
| Врач | `doctor` | Работает со своими осмотрами; врач по спортивной медицине дополнительно выдаёт заключения (флаг `can_issue_conclusion`) |
| Спортсмен | `athlete` | Только свои данные |
| Тренер | `coach` | Только статус допуска подопечных |

Один пользователь — одна роль. Доступ проверяется на уровне сервиса по роли и принадлежности данных (RBAC).

## 2. Принципы

1. **Минимум данных на роль.** Каждая роль видит только то, что нужно для её работы.
2. **Тренеру диагнозы не показываем**: только статус «допущен / допущен с ограничениями / не допущен / нужен повторный осмотр» и срок действия.
3. **Регистратура видит статусы и записи, но не результаты осмотров.**
4. **Администратор по умолчанию не читает медданные**; работает со справочниками, пользователями и журналом.
5. Все действия фиксируются в журнале (см. 08).

## 3. Матрица прав

Обозначения: ✓ — полный доступ в рамках роли; «свои» — только свои данные; «чтение» — только просмотр; «—» — нет доступа.

| Действие | admin | registrar | doctor | athlete | coach |
| --- | --- | --- | --- | --- | --- |
| Создать пользователя (врач, регистратура, админ) | ✓ | — | — | — | — |
| Зарегистрировать спортсмена | ✓ | ✓ | — | — | — |
| Редактировать свой профиль | ✓ | ✓ | ✓ | свои | ✓ |
| Справочники и программы осмотров | ✓ | чтение | чтение | чтение | чтение |
| Создать слоты расписания | ✓ | — | свои | — | — |
| Просмотр свободных слотов | ✓ | ✓ | ✓ | ✓ | — |
| Записать на слот | ✓ | ✓ (за спортсмена) | — | свои | — |
| Отменить запись | ✓ | ✓ | — | свои | — |
| Открыть дело на обследование | ✓ | ✓ | — | — | — |
| Отметить приход на приём | — | ✓ | — | — | — |
| Внести результат осмотра | — | — | ✓ (своя специальность) | — | — |
| Внести нагрузочное тестирование | — | — | ✓ | — | — |
| Выдать заключение | — | — | ✓ (только `can_issue_conclusion`) | — | — |
| Видеть результаты осмотров | — | — | ✓ (по делам, где участвует; спортврач — все) | свои | — |

| Админка | ✓ | — | — | — | — |

## 3.1. Привязки

- Тренер связан со спортсменами через `athlete_profiles.coach_id`.
- Врач участвует в деле, если ему назначен хотя бы один осмотр или запись по этому делу.

## 4. Принятые решения

- Заключение скачивает и спортсмен, и регистратура (печать бумажной копии для подписи и печати).
- Врач видит дела, где он участвует; врач по спортивной медицине видит все.
