# Чек-лист перед боевым деплоем

Решения заказчика, которые сознательно отложены до деплоя на сервер.

## Обязательно перед деплоем

- **CSP (Content-Security-Policy).** Сейчас заголовка нет. Для включения нужно:
  - перейти на `@alpinejs/csp` и вынести `x-data`/`x-text` в `Alpine.data(...)` в `app.js` (стандартный Alpine требует `unsafe-eval`);
  - заменить `x-show` (пишет inline-style) на `hidden`;
  - отключить встроенные стили HTMX: `<meta name="htmx-config" content='{"includeIndicatorStyles":false}'>`;
  - задать заголовок в `nginx.conf`.
- **TLS:** сертификаты, домен, редирект 80 → 443 (в `nginx.conf` сейчас TODO).
- **Секреты:** реальные `SECRET_KEY`, `POSTGRES_PASSWORD` вместо `change-me`; пин версии образа `uv`.
- **Не запускать `seed-demo`** на проде (публичный пароль).
- **Бэкапы Postgres** (pg_dump по расписанию + проверка восстановления), ротация логов Docker, файрвол (только 80/443).
- **Подсеть Docker:** проверить `ip route` на VPS, при пересечении задать `APP_SUBNET`/`NGINX_IP` в `.env`.
- **IPv6:** если нужен, включить по комментарию в `docker-compose.yml`.
- **Статика:** копирование в образ nginx или копия репозитория на сервере (`./app/static` монтируется с хоста).
- **CI:** lint, тесты, сборка образа.
